# Datascope Course

מערכת הלמידה של הקורס **מידענות רב־תחומית (מקוון)**.

## דטהסקופ — שירותי מחקר ומידענות

הסטודנטים פועלים כמידענים מתחילים. בכל יחידה מתקבל תיק לקוח חדש, והלמידה מובילה מהבנת הצורך ועד להמלצה מקצועית מבוססת מידע.

## עקרונות

- Moodle משמש לכניסה, הודעות, הגשות וציונים.
- אתר דטהסקופ הוא סביבת הלמידה המרכזית.
- הקורס מלמד תהליך עבודה מקצועי, ולא רק שימוש במאגרים.
- כל יחידה בנויה מרכיבים קבועים ורב־פעמיים.
- האתר מותאם לעברית, RTL, מובייל ונגישות.

## תהליך העבודה

לקוח → צורך → שאלת מחקר → מקורות → איסוף → הערכה → ניתוח → המלצה
