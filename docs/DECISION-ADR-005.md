# ADR-005: Split the course introduction into four guided pages

## Decision

The introduction is implemented as four sequential HTML pages rather than one long homepage.

- `HOME-00`: University welcome and course administration
- `HOME-01`: Transition from librarianship to organizational information work
- `HOME-02`: DataScope employee onboarding
- `HOME-03`: DataScope Training Academy entry

## Rationale

This structure gives each page one primary instructional purpose, creates a visible transition from university to company, and prepares a repeatable page pattern for later course units.
