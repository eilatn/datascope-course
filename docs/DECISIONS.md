# יומן החלטות

## ADR-001 — Moodle אינו סביבת התוכן המרכזית
Moodle ישמש לניהול, הגשות וציונים. חוויית הלמידה תהיה באתר דטהסקופ.

## ADR-002 — אתר סטטי בשלב הראשון
HTML, CSS ו-JavaScript ללא framework וללא build.

## ADR-003 — זהות
דטהסקופ — שירותי מחקר ומידענות.

## ADR-004 — שם הקורס
מידענות רב־תחומית (מקוון) מופיע בעיקר בכניסה ובמקומות אקדמיים.

## ADR-005 — לא להנדס מוקדם מדי
נשלים יחידה אחת לפני החלטה על JSON, Markdown או CMS.
